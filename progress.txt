Phase 4 — Bug Hunt & E2E .................... IN PROGRESS
  [x] BUG (P0): catch-all `/` StaticFiles mount was registered BEFORE /api/health &
      /api/version, so both 404'd in every built deployment (frontend/dist present).
      Also broke the post-update health check. Fixed by moving the API routes above
      the static mounts in main.py + regression test
      (test_smoke::test_catch_all_static_mount_is_last).
  [x] BUG (P1, multi-port): NetworkService.get_lan_neighbours() filtered ARP entries
      on the legacy single settings.network.lan_interface, so /clients/sync-leases
      missed static-IP clients on secondary LAN ports / VLAN sub-interfaces. Now uses
      settings.all_lan_interfaces() with legacy fallback. Tests: test_network.py.
  [x] BUG (P2, consistency/race): portal.py wrote config via its own non-atomic,
      non-locked read-modify-write (_persist_portal_to_yaml), bypassing the Phase 2
      config_lock + atomic writer — could clobber concurrent config writes. Now goes
      through config_lock + persist_config(). Tests: test_portal.py.
  [x] HARDENING: portal web-login password/username now compared with
      secrets.compare_digest (constant-time) instead of !=.
  [x] Routed NetworkService._run through the central command runner (fakeable),
      matching firewall/dnsmasq; dropped now-unused asyncio import.
  Reviewed (no action needed): scheduler tick/due logic, firewall allow/intercept +
  cache invalidation, captive-portal middleware self-heal, dnsmasq lease parsing,
  clients auth/deauth/sync flows.
